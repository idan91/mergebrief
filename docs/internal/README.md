# Internal docs

Owner-only material. These files are tracked in the development repository and excluded from the public release snapshot, so nothing shipped may link here.

- `adr/`: the architecture decision records.
- `archive/`: the retired commercial strategy and validation checklists.
- `dev/`: research notes and one-off walkthroughs behind shipped work.
- `interviews/`, `problem-framing/`, `reviews/`, `competitive-analysis.md`: discovery and market material.
- `mvp/`: the retired Phase 1 experiment, the parked playbook seed and the one hand-labeled brief.
- `mockup/`: the pre-product interview mockup.
- `release-guide.md`: the operator manual for publishing a release to the public repository, setup and recovery included.
- `next-steps.md`, `oss-roadmap.md`: retired planning documents; the ticket board is the live plan.
- `system-overview.md`: the first design snapshot; `docs/architecture.md` is the current one.
- `ticket-board.md`: the board link and the ticket status workflow the root `AGENTS.md` points to.
