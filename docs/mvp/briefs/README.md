# Phase 1 Briefs

Hand-labeled briefs for the Phase 1 wizard-of-Oz C test. One file per PR. Format follows the structure in `../phase-1.md` (Hand-Labeling Protocol section).

**Before labeling, read [`labeling-workflow.md`](./labeling-workflow.md)** — the step-by-step process, in the order that produces best calibration. Different from the order the brief file lists its sections.

**Keep [`../labeling-schema.md`](../labeling-schema.md) open while labeling** — the controlled vocabulary: every valid Category / Concern / Role / Risk-Surface token + the LoC and grouping quick-rules, in one place.

Naming convention:
- `<repo>-<PR-number>.md` — full **Treatment** brief (change-groups + categorization + playbooks + risk surface + concern/LoC + tricky-cases)
- `<repo>-<PR-number>.baseline.md` — **Baseline B′** (Treatment minus Category labels / playbooks / risk-surface; grouped substrate retained). Generated by stripping the Treatment brief, not labeled separately.

Each brief draws categories from `../playbooks.md` and risk-surface attributes from `../risk-surface.md`.

**Chunk line-range convention.** Each chunk row carries the *actual changed lines*, split by side:
`· (+) <added, new-side> · (−) <removed, old-side>`

- **Added** = new-side line numbers (where added code sits *after* the change).
- **Removed** = old-side line numbers (where deleted code sat *before*).
- These are the *changed* lines only — NOT the `@@` hunk window (which includes unchanged context). Don't confuse the two.
- `—` means none on that side. A deleted file shows `(+) — · (−) 1-N`.
- Many disjoint ranges in one file = the change is scattered → a **chunk-split candidate** if those spans differ in concern or intent.

These ranges are *location* (for navigation + diff rendering). They are distinct from **adjusted LoC** (the *counts*, after move/generated exclusion) — keep both.

Generate with the parser in `/tmp/diffranges.awk` (or inline):

```bash
gh pr diff <n> --repo <owner>/<repo> | awk '
  function comp(s,  n,a,i,j,t,o,st,p){n=split(s,a," ");if(n==0)return"—";
    for(i=1;i<=n;i++)for(j=i+1;j<=n;j++)if(a[j]+0<a[i]+0){t=a[i];a[i]=a[j];a[j]=t}
    o="";st=a[1];p=a[1];for(i=2;i<=n;i++){if(a[i]+0==p)continue;if(a[i]+0==p+1){p=a[i];continue}
    o=o(o==""?"":", ")(st==p?st:st"-"p);st=a[i];p=a[i]}return o(o==""?"":", ")(st==p?st:st"-"p)}
  /^diff --git/{ih=0;op="";next} /^--- a\//{op=$2;sub(/^a\//,"",op);next} /^--- /{op="";next}
  /^\+\+\+ b\//{f=$2;sub(/^b\//,"",f);F[f]=1;ih=0;next} /^\+\+\+ \/dev\/null/{f=op;F[f]=1;ih=0;next} /^\+\+\+ /{ih=0;next}
  /^@@ /{h=$0;match(h,/-[0-9]+/);o=substr(h,RSTART+1,RLENGTH-1)+0;match(h,/\+[0-9]+/);n=substr(h,RSTART+1,RLENGTH-1)+0;ih=1;next}
  ih&&/^\+/{A[f]=A[f]" "n;n++;next} ih&&/^-/{D[f]=D[f]" "o;o++;next} ih&&/^ /{o++;n++;next} ih&&/^\\/{next} {ih=0}
  END{for(f in F)printf "%s\t(+) %s\t(−) %s\n",f,comp(A[f]),comp(D[f])}'
```
