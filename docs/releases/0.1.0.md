## The first release

MergeBrief runs on your own host: one `docker compose up -d --wait` from the
shipped compose file brings up Postgres, the API, the web tier and the worker,
and every push to an open pull request gets its brief generated in the
background. The `mergebrief` CLI on npm drives the same API for humans and
agents.

Start at [`docs/self-host/compose.md`](https://github.com/Idan91/code-review/blob/v0.1.0/docs/self-host/compose.md).
Install the CLI with `npm i -g mergebrief@0.1.0`.
