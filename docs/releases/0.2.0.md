## Search and sort in the Inbox

- **Search.** A search field leads the Inbox controls, and `/` focuses it.
  Each word must match the title, and digits also match a pull request
  number. The text rides the address as `q`. The URL box moves to `U`.
- **Sort by Created, either direction.** The Sort menu lists Updated,
  Generated and Created, newest or oldest first. A pull request stored
  before this release sorts last until GitHub next reports it.
- **The demo shows a real pull request,** with two revisions.

## Upgrading

The usual chain. One migration adds a nullable column on start.
