## Documentation

- **The cloud guide works on any provider.** [Deploy on a server](https://github.com/idan91/mergebrief/blob/v0.3.2/docs/self-host/server-deployment.md) replaces the Hetzner and EC2 guide. You pick a VPS or a cloud VM, then where Postgres runs: on the server, managed over the internet, or managed on a private network. Provisioning is a list of what the server needs instead of one provider's console, and Neon, Supabase and Amazon RDS keep a short section each for their quirks.
