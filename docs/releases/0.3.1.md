## Documentation

- **A guide for reviewers.** [Review a pull request](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/use/reviewing.md) walks through reading a brief, acting on risk flags, commenting, picking up after new pushes and submitting your review, with keyboard shortcuts and settings. [Risk flags](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/use/risk-flags.md) explains each of the 21 built-in flags.
- **Trigger conditions have their own page.** [Trigger conditions](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/repo-config/trigger-conditions.md) opens with the setup most teams want and gives a copy-paste recipe for each condition: drafts, CI, named checks, size, paths, review bots, review requests, labels, base branches and manual only.
- **Repository config is task pages.** [Settings](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/repo-config/settings.md), [risk policy](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/repo-config/policy.md) and [instructions](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/repo-config/instructions.md) each lead with a snippet and end with a check that it applied.
- **Setup follows the order you meet it.** [Register the GitHub App](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/github-app.md) follows GitHub's form field by field. [docker compose](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/compose.md) covers an existing nginx or Traefik proxy, starting on boot and a first backup. The [configuration reference](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/configuration.md#apply-a-change) says which service to restart for each setting.
- **Operating pages are split by task:** [upgrade](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/upgrade.md), [back up and restore](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/backup-restore.md), [rotate secrets](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/secrets.md), [data and scaling](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/data-and-scaling.md), [spend cap](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/spend-cap.md) and [uninstall](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/uninstall.md). [Troubleshooting](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/troubleshooting.md) is keyed by what you see, including each error a failed brief shows.
- **Fixed instructions.** The provider-failure alert in [Logs, alerts and tracing](https://github.com/idan91/mergebrief/blob/v0.3.1/docs/self-host/observability.md) matches on `kind`, the field failures carry. If you copied the earlier alert, it never fired: replace it.

## Docs site

- **The site carries the MergeBrief look:** its logo and wordmark, the app's surfaces and type, styled callouts and tables, and a GitHub link.
- **A home page** sends you to reviewing, running an instance, configuring a repository or the CLI. The sidebar puts using MergeBrief first and splits self-hosting into Set up, Configure, Secure and Operate.
- **Search results say where they live,** such as "Repo config / Trigger conditions" or "Releases / 0.3.0".
