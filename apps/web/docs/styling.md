# apps/web styling

The stylelint mechanics behind `DESIGN.md`: which properties read a token, the units, and how a disable is written. `pnpm -C apps/web lint` (stylelint) holds every rule marked as a stylelint rejection.

## Values

- Zero raw colors/font-sizes/radii/shadows in `.module.scss`: semantic-scale tokens/mixins only (no value-named tokens). An off-scale value stays raw behind a line-scoped stylelint disable that names its reason, or earns a component-local token with a one-line justification. Every stylelint disable carries a `-- <reason>`; `reportDescriptionlessDisables` holds it.
- State fills: a warning, crimson, green or accent fill over transparent reads a `--color-<state>-tint-<strength>` token at faint 5%, subtle 8%, medium 12% or strong 18%; a fill whose colour varies (`--badge-color`, an added or removed row's `--row-hue`) mixes it at a `--tint-*` strength. An unchanged diff row's 6% Text 1 hover, edges, washes, flashes and surfaces lifted toward a colour stay component-owned.
- Units: text and everything text-coupled is rem via `functions.to-rem(<px>)`: font sizes, touch-target min-heights, measure caps, menu/dialog widths. Chrome stays px: borders, radii, shadows, icon boxes, decorative geometry, breakpoints. Ambiguous sizing → px.
- Spacing: `margin`, `padding`, `gap` and their longhands read a `--space-*` step (2, 4, 6, 8, 10, 12, 14, 16, 24, 32, 48, 64px), `0`, `auto`, or a layout variable (any custom property, or a module-namespaced Sass variable such as `layout.$story-group-gap`), alone or inside `calc()`, `clamp()`, `max()` or `min()`. Stylelint rejects any length literal there in any letter case, any file-local Sass variable (`$pad`, `#{$pad}`), and any `functions.to-rem()` over a number or a file-local variable; percentages, viewport units, `env()` and unitless factors pass. A value within 2px of a step takes the step. One no step holds stays `functions.to-rem(<px>)`, or px when it tracks a border or an icon box, behind `/* stylelint-disable-next-line declaration-property-value-allowed-list -- <reason> */`. A spacing value passed to a mixin is invisible to the rule: a spacing parameter (`layout.wrapping-columns($row-gap)`) takes a `--space-*` step.
- Line height: `line-height` reads a `--line-height-*` step (control 1, display 1.1, heading 1.2, compact 1.35, body 1.5, reading 1.7), a px or rem length such as `functions.to-rem(20px)` for a fixed line box, a custom property, a module-namespaced Sass variable, `inherit` or `0`. Stylelint rejects any other number, a `%` or font-relative unit (`145%`, `1.45em`, `1.5lh`) and any file-local Sass variable (`$lh`, `#{$lh}`). Pick the step by the text's job, not the nearest number.
- Stacking: `z-index` reads `functions.get-z-index("<layer>")`, a name from `$z-layers` in `styles/_functions.scss` (lowest first; a layer resolves to its position times 10), or -1, 0 or 1 inside a component's own stacking context. Stylelint rejects any other value. A new thing that overlaps another takes its own entry where its order needs it; two things share an entry only where they never share a stacking context or never overlap.
- Motion: `transition` and `animation` durations and delays read a `--motion-*` token (fast 120ms, base 180ms, slow 320ms, slide 260ms, spin 700ms, read and flash 1.4s), another custom property or 0. Stylelint rejects any other time literal and any file-local Sass variable (`$dur`, `#{$dur}`) there, and in a `.module.scss` a time literal held in a custom property or Sass variable (`--dur: 300ms`, `$dur: 200ms`); a duration one component alone owns keeps a line-scoped disable naming why (SkeletonRows' 1600ms shine cycle tracks `SHINE_CYCLE_MS`). Hover and colour changes take fast; an entrance takes base and its exit fast, except the focus shortcuts strip, which closes over base as it opens, and the sidebar's push, which opens over slide and closes over base because it moves the reading column.

## Custom properties and shared jobs

- A module declares a custom property only for a value its component alone owns. A job two components share is one mixin, function or token (`mixins.dimmed` for every disabled control, `mixins.user-select`, `mixins.safe-area-bleed`, `functions.inner-radius`, `functions.ink-lift`, `functions.edge-bar` for every inset edge bar, `functions.ring` and `functions.inset-ring` for every ring, `--ring-room`, `--diff-line-box`); a property that only renames a global token is deleted and the token read directly. The layout variables (`--header-*`, `--focus-*`, `--sidebar-*`, `--chunk-*`) stay where they are.
- A module custom property, or a Sass variable outside a `@function`, holds no raw colour (a colour function or hex) and no shadow geometry, written out or routed through `#{}`: `house/custom-property-no-raw-value` (`stylelint-custom-property-no-raw-value.mjs`) holds it in `*.module.scss`, reading every interpolation but a `functions.*` shape builder as a length, and `tokens.scss` is the owner. A value one component alone owns keeps a line-scoped disable naming why.
- Popover's panel owns the floating surface (edge, corner, fill, shadow); a consumer sets only its size, padding and layer.
- Sass keeps a custom property's value as written, so a function call there is interpolated (`--x: #{functions.inner-radius(...)}`); a property whose name is itself interpolated (`#{$edge}: ...` in `mixins.safe-area-bleed`) is parsed as a plain declaration, and Sass evaluates its value.

## Comments

Styling carries no comments. In a `.module.scss` rule, a token or a `style` object, the constraints that earn one are: a browser bug or missing feature, a value that must track another file, a cascade trap, or a measured constraint an innocent edit would silently break. Naming the visible layout mechanism does not. Test: a comment that would survive pasting into another project's stylesheet says nothing about this one.

## Palette and brand assets

- `apps/docs-site/.vitepress/theme/tokens.css` restates the palette in `src/styles/tokens.scss` by hand: a palette change updates it in the same PR, and `styles/docs-site-tokens.test.ts` holds its dark theme to the tokens.
- `components/icons/mergebrief-*.svg`, `public/favicon*`, `public/apple-touch-icon.png`, `public/og-image.png` and the GitHub App logo `docs/media/github-app-logo.*` are committed brand assets with no generator. The favicons, touch icon, share image and App logo draw the mark's shape and the brand, ground and Text 1 colours: a change to either redraws them in the same PR.
- The App logo's PNG is a 512px export of its SVG; the two change together. `favicon-16.png` is drawn on whole pixels, never scaled from the mark. apps/docs-site ships byte-identical copies of the favicons and the touch icon: a change lands in both. `utils/share-image` restates `og-image.png`'s 1200x630; its test holds the two equal.
