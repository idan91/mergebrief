# tools/brand: agent notes

The brand generator: two masters in `src/master/` become every mark, favicon, tile and share image the app and the docs site ship. Nothing in an app or package imports it; it runs by hand and its output is committed.

Repo-wide conventions apply (root AGENTS.md); refinements below.

## Map

- `src/master/mark.svg` is the Rounded Merge Mark as drawn, one evenodd path on a 257 grid. Edit it only to change the mark.
- `src/master/wordmark.svg` is generated by `pnpm -C tools/brand outline-wordmark`: Archivo at `wdth` 112, `wght` 700, tracked -0.015em, outlined from the variable font at a pinned google/fonts commit and refused unless its SHA-256 matches `consts.ts`. Its view box centres the cap height, so a flex row that centres it centres the capitals.
- `pnpm -C tools/brand generate` (`src/generate.ts`, the composition root) writes every file `src/assets.ts` lists, under `apps/web`, `apps/docs-site` and `out/`. `out/` is gitignored: `out/bot-avatar.png` exists only after a `generate` run, for uploading to the GitHub App by hand.

## Invariants

- **Output is a function of the masters.** No system font, no clock, no network in `generate`; a `generate` run over unchanged masters writes no diff. Nothing checks the committed files against a fresh run: after a master or const change, run `generate` and commit everything it writes.
- **The 16px favicon is drawn, not scaled**: the mark's 11 grid cells as whole 3px squares from the top-left, no anti-aliased pixel. A 15px grid cannot centre in 16 on whole pixels, so the last column and row stay empty. `findMarkCells` reads the cells back from the master.
- **Colours are the brand decisions, restated**: `consts.ts` holds the brand (#e91f00), the ground (#020203) and Text 1 (#ececee) as decided. A tool never imports app source, so a change to any of them in the app's palette moves here, and regenerates, in the same PR. The share image's 1200x630 is restated in apps/web's `utils/share-image`, whose test reads the committed PNG's size.

## Verification

`pnpm -C tools/brand typecheck`; after a master change, `generate` and commit what it writes.
