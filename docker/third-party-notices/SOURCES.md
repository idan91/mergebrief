## libvips

sharp-libvips version: 1.3.4

The image runs sharp with its prebuilt libvips, the npm package `@img/sharp-libvips-<platform>@1.3.4`, unmodified. Its libraries load as separate shared objects from that package's `lib/` folder under `/app/node_modules/.pnpm/`, so a build of your own with the same interface can replace them.

THIRD-PARTY-NOTICES.md lists each library and its licence; LGPL-3.0.txt, GPL-3.0.txt, MPL-1.1.txt hold the full texts. Each library's source is the upstream download below, the one the release's build fetched, followed by any patch it applied. The build itself is https://github.com/lovell/sharp-libvips/tree/v1.3.4 (`build/posix.sh`, versions pinned in `versions.properties`).

## elkjs

elkjs version: 0.9.3

The web app ships the npm package `elkjs@0.9.3`, unmodified, under the Eclipse Public License 2.0 (EPL-2.0.txt): minified into Mermaid's lazily loaded layout chunk under `/app/apps/web/dist/client/assets/`, and as the package itself under `/app/node_modules/.pnpm/`.

Its source is the release tag, https://github.com/kieler/elkjs/archive/refs/tags/0.9.3.tar.gz (https://github.com/kieler/elkjs/tree/0.9.3). That tag compiles the ELK layout algorithms from their Java source, https://github.com/eclipse/elk, with GWT, as its README's Building section describes.
